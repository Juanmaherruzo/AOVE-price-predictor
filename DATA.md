# Data provenance

Everything needed to reproduce the results table is in this repository: the two
derived CSVs in `data/` and the trained checkpoint in `AOVE_model/`. Run
`aove-benchmark` and you should get the published numbers.

This file records where each column comes from — including the three that are
**not measured data**.

---

## Climate — `data/climate_dataset.csv`

| | |
|---|---|
| **Source** | [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api), `models=era5_land` |
| **Underlying dataset** | ERA5-Land reanalysis, ECMWF / Copernicus Climate Change Service |
| **Coverage** | 13 Andalusian olive-growing locations, daily 2009-12-28 to 2026-04-27, aggregated to weekly (11,089 rows) |
| **Columns** | `rainfall_mm`, `temp_max_c`, `water_deficit_mm`, weighted by `surface_ha` |
| **Licence** | Open-Meteo data is CC BY 4.0. ERA5-Land is Copernicus, free to redistribute with attribution. |

> Generated by Copernicus Climate Change Service information (ERA5-Land),
> retrieved via Open-Meteo. Neither ECMWF nor the European Commission is
> responsible for any use of this data.

## Consumer price index — `ipc_monthly`

| | |
|---|---|
| **Source** | INE (Instituto Nacional de Estadística), public JSON API, series `IPC251852` |
| **Frequency** | Monthly, forward-filled onto the weekly grid |
| **Licence** | Spanish public sector information, reusable under Ley 37/2007 with attribution |

## EVOO origin price — `aove_price_eur_kg`

| | |
|---|---|
| **Source** | Weekly olive oil price series published by the European Commission (DG AGRI agri-food data portal) |
| **Frequency** | Weekly, 2010-01-04 to 2026-04-27 (307 distinct values over 850 weeks) |
| **Licence** | Commission Decision 2011/833/EU — reuse permitted, **including commercial use**, with attribution |

This is the target variable and the source of `aove_lag_price`.

## The three proxy columns — not measured data

`diesel_price_eur`, `surface_delta_pct` and `stock_delta_pct` are **hard-coded
annual constants** defined in `aove/data_prepare.py`, interpolated onto the
weekly grid. They are not downloaded from anywhere.

| Column | Where it lives | Distinct values / 850 weeks |
|---|---|---|
| `diesel_price_eur` | `DieselLoader.ANNUAL_PROXY` | 16 (one per year) |
| `surface_delta_pct` | `DatasetAssembler.SURFACE_ANNUAL` | 11 |
| `stock_delta_pct` | `AICALoader.ANNUAL_STOCK_KT` + `SEASONAL_OFFSET` | 27 |

They were written as stand-ins for MITECO diesel prices and AICA stock figures
during the first build and were never replaced. `data_prepare.py` logs a warning
when it falls back to them, and accepts real CSVs via `--diesel-csv` and an AICA
directory if you have them.

**Why this matters for the results.** A feature that changes once or twice a year
cannot carry information about next week's price. Three of the five macro inputs
are step functions at annual resolution, which is part of why the model does not
beat a persistence baseline — see the results table in the README. Any reading of
feature importance on this model has to account for that.

## Reproducing the results

```bash
pip install -e ".[dev]"
aove-benchmark --json benchmark.json
```

Expected output on the published data and checkpoint:

| Predictor | MAE (EUR/kg) | R² |
|---|---|---|
| Persistence | 0.057 | 0.987 |
| Random walk with drift | 0.058 | 0.987 |
| Bimodal LSTM | 0.073 | 0.982 |

To rebuild the datasets from source instead:

```bash
aove-prepare --price-csv ./data/precio_historico.csv
```

Climate and CPI are downloaded live; the three proxy columns are regenerated
from the constants above unless you supply real files.
