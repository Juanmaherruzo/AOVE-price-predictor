# Model Checkpoint — Not Publicly Distributed

The trained model checkpoint (`best_aove_model.pth`) and the proprietary datasets
(`climate_dataset.csv`, `macro_dataset.csv`) are **not included in this repository**.

## Why

The checkpoint is the result of months of data assembly, engineering and training on
proprietary market and climate data. Distributing it would allow anyone to replicate
the product without the underlying effort.

## Architecture is fully open

The complete model architecture, ETL pipeline, inference engine and API are published
here. Anyone can review the methodology, retrain on their own data, or adapt the
code for other commodity price-forecasting problems.
